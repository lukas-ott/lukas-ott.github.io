A digital version of the board game Splendor, developed by six students as a university project
at the University of Mannheim.

- I implemented the REST API for user management and game statistics. The project uses Jakarta
  REST/Jersey, SQLite via JDBC and WebSocket communication.
- I combined product responsibilities with development: I planned sprints and coordinated
  deliveries.
